# 駿河屋価格トラッキング 取込（Edge拡張）

通常のEdgeで表示できた駿河屋商品ページを、ローカルで起動中の駿河屋価格トラッキングへ渡します。アクセス確認を回避する機能はありません。

## インストール

1. Edgeで `edge://extensions` を開く
2. 左側の「開発者モード」をオンにする
3. 「展開して読み込み」を押す
4. この `browser-extension` フォルダーを選ぶ
5. ツールバーの拡張機能一覧から「駿河屋価格トラッキング 取込」を固定する

## 使い方

1. 駿河屋価格トラッキングを `npm.cmd run dev` で起動する
2. Edgeで駿河屋の商品詳細ページを通常どおり開く
3. 商品ページが表示された状態で拡張機能を開く
4. 「この商品を記録」を押す

同じ商品で再実行すると、新しい価格履歴として追加されます。

## 毎日の自動更新

1. 拡張機能を開く
2. 「自動更新を有効にする」をオンにする
3. 実行時刻を選ぶ
4. 同時に開く商品タブ数を1〜100で選ぶ（初期値10）
5. 「設定を保存」を押す

指定時刻に、登録済みの商品ページを設定した数だけ並列に開きます。各処理枠では、前の商品を記録してから1秒後に次の商品を開きます。「今すぐ全商品を更新」も同じ設定です。商品ページの読込と解析は並列で行い、取得できた商品を処理の最後にSQLiteの1トランザクションへ一括保存します。途中停止やアクセス確認の検出時も、それまでに取得できた商品は一括保存します。

制約:

- 指定時刻にEdgeと駿河屋価格トラッキングの両方が起動している必要があります。
- 指定時刻を過ぎてからEdgeを起動した場合、その日の未実行分を開始します。
- ローカルアプリに接続できなかった場合は、Edgeが起動している間、15分後に再試行します。
- Cloudflareのアクセス確認を検出した場合は、その時点で全商品の更新を停止します。確認の回避や自動操作は行いません。
- 商品ごとに新しいタブが一時的に作成され、記録後に閉じられます。
- PCの電源が切れている間は実行できません。

Windowsへのログイン時にローカルアプリも起動するには、`Win + R`で`shell:startup`を開き、リポジトリ直下の`start-tracker.cmd`へのショートカットを置きます。起動したコマンド画面を閉じるとローカルアプリも停止します。

## 商品の自動追加

1. 駿河屋で追加したい商品の検索または絞り込みを行う
2. 検索結果ページのURLをコピーする
3. 拡張機能の「駿河屋の検索結果URL」へ貼り付ける
4. 未登録の追加件数を1〜1,000件で指定する
5. 「未登録商品を自動追加」を押す

初期値は「ビジュアルノベル（美少女ゲーム）」の検索結果です。検索結果のページと商品詳細の両方を設定した同時タブ数で確認し、登録済みの商品番号を除外して記録します。1,000件では検索結果約42ページを対象にします。検索結果の件数が指定数より少ない場合は、見つかった分だけ追加します。

自動追加中もEdgeとローカルアプリを起動したままにしてください。Cloudflareのアクセス確認を検出した場合は停止します。途中まで成功した商品は保存されるため、再実行時には登録済みとして除外されます。

途中で止める場合は「実行中の処理を停止」を押します。現在開いている1商品を処理した後に停止します。
