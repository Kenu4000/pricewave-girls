# 登録商品の巡回実行順

登録商品の周期ごとの対象選定は、従来どおり `browser-extension/balanced-crawl-scheduler.js` の42日均等化を使う。

対象に選ばれた商品の**実際の巡回開始順**は、長周期の商品から次の順にする。

1. 14日
2. 7日
3. 3日
4. 1日

この順序変更は、3/7/14日商品の「本日どの商品を対象に選ぶか」には影響しない。まず従来どおり超過率・最終取得から本日の対象を選び、その後に実行順だけを周期の降順へ並べ替える。

同じ周期内では、既存の優先順位を維持する。したがって長周期商品の選定回数や42日サイクルの均等化は変わらない。

目的は、アクセス確認などで巡回が途中停止した場合でも、巡回頻度の低い14日・7日商品を1日商品より先に処理すること。
